## 更新约定

- 先执行 `npm run build:e2e`，使用隔离构建及临时房间，不能加入已有玩家的房间取景。
- 使用合成玩家名字，通过真实创建、加入、准备、组队、投票和任务提交操作到达目标阶段。
- 等待字体与图片加载，滚动至页面顶部；核对顶栏、任务进度、选人状态和按钮没有意外被裁切。
- 手机端保持真实窄屏布局，不把桌面截图缩小后冒充手机端。
- 角色卡逐张截图，保留完整卡面、角色名和说明，按阵营排列；不要从整页缩略图再次截取。
- 不截取地址栏、入场暗号、分享链接、会话令牌、调试面板、私人聊天或真实玩家数据。
- 更新对应 JPEG 和本页的日期、场景说明，再执行 `npm run docs:check` 并预览根 README。

根 README 使用标准 Markdown 标题、链接、图片和表格，不依赖 HTML 折叠块、手工锚点、内联 CSS 或 Markdown 与 HTML 的混合排版。修改时在桌面和手机视口各预览一次，并检查图片链接和标题导航。
