# 代码与素材许可

## 项目代码

项目自行编写的源码、脚本、配置、测试和文档采用根目录 [MIT](../../LICENSE)，版权署名为 `Avalon contributors`。第三方依赖、图片和音频不会因此自动变为 MIT。

`package.json` 的 `private: true` 用于避免误发 npm，不影响 GitHub 源码公开。提交贡献前请确认有权提供相应内容，见[贡献指南](../../CONTRIBUTING.md)。
