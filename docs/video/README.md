# 宣传演示片

[avalon-promo.mp4](avalon-promo.mp4) 是根 README 使用的 64 秒宣传演示片，1920 × 1080、30 fps，H.264 视频加 AAC 立体声，用于展示项目，不是前端运行时资源。成片制作于 2026-11-12，对应当前的烛火议事厅主题。

| 时间 | 画面 |
| --- | --- |
| 0:00–0:07 | 标语与标题，背景为项目圆桌美术 |

| 0:12–0:42 | 开房入席、身份揭晓、队长组队、发车表决、执行任务的实机录屏 |

| 0:58–1:04 | 项目地址、许可与人数信息 |

## 来源

- 对局画面来自项目的隔离生产构建（`npm run build:e2e`），使用独立回环端口、临时数据库和五名合成名字的真人客户端，从建房到刺杀完整走完一局；没有接入真实房间、麦克风或玩家数据。
- 录屏通过浏览器截屏流逐帧采集，桌面视口 1440 × 1180，手机视口 390 × 844。界面内容、计时和结算均来自真实服务端状态，没有修改 DOM 或模拟结果。
- 画面中的鼠标光标与点击涟漪是后期叠加的，位置取自录制时的真实点击点。录屏片段有裁切、缩放，开房段落按 4 倍速压缩了等待加入的时间。
- 角色卡来自当前收藏馆的逐张截图；标题、说明文字和转场为后期合成。

## 更新约定

- 界面或玩法有明显变化时重新录制，不拿旧录屏拼接新界面。
- 只用隔离构建、临时房间和合成名字，不截取地址栏、入场暗号、分享链接、会话令牌或真实玩家数据。
- 片中的功能描述须与当前代码一致；无法从代码确认的说法不放进片子。
- 仓库内的成片控制在 10 MB 左右，同时更新 [README 封面](../images/promo-poster.jpg)和本页的日期与内容表，再执行 `npm run docs:check`。
- 根 README 的内嵌播放器使用在 GitHub 网页上传后生成的 `user-attachments` 链接，必须单独占一行才会渲染成播放器。成片更新后要重新上传，并替换 README 里的这个链接。
